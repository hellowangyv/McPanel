📖 部署 Agent 指南

如何部署分支节点 (Node Agent)

  1. 把 node_agent.py、server_manager.py、requirements.txt 拷贝到远程服务器
  2. 远程服务器安装依赖: pip install -r requirements.txt
  3. 启动 Agent，设置共享 Token（与下方填写保持一致）: 
    set NODE_API_TOKEN=你生成的随机密钥
python node_agent.py --host 0.0.0.0 --port 58765
  4. Agent 启动后会打印监听地址和 Token，确保 http://远程IP:58765/health 能访问
  5. 在下方表单填入节点名称、API URL (http://远程IP:58765)、以及上面的共享 Token，点击添加即可
  6. 添加完成后点击 Ping 测试，状态变为"在线"说明通信正常

💡 建议：生产环境为 Agent 配置 Nginx 反向代理 + HTTPS，并设置 --allow-from 主面板IP白名单。
